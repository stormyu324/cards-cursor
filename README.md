# 斗地主

一个在浏览器里打开就能玩的斗地主小应用。你坐庄下方，和两位电脑打三人局。

## 玩法

- 叫 1 到 3 分，最高分当地主，并拿走三张底牌。三个人都不叫就重新发牌。
- 牌型按常见的欢乐斗地主：单张、对子、三张、三带一、三带二、顺子、连对、飞机、四带二、四带两对、炸弹、王炸。
- 顺子、连对、飞机不能带 2 和大小王。炸弹压普通牌，王炸最大。
- 每出一个炸弹或王炸，倍数翻倍。春天、反春天再翻一倍。
- 积分记在本机浏览器里。

## 联机

点右上角“联机”创建房间，把邀请链接或 4 位房间号发给朋友，最多三个真人同桌；空位和掉线的玩家由电脑代打，每手限时 40 秒。

联机需要服务端：`server/room.js` 是房间规则（座位、发牌、校验、电脑补位），`server/durable.js` 把它包成 Cloudflare Durable Object，并提供 `api/create` 和 `api/room/<房间号>/ws` 两个接口。牌局由服务端裁决，每位玩家只收到自己的手牌。用 `npm start` 起的静态服务没有这些接口，只能玩单机。

## 本地运行

```bash
npm start
```

然后打开 <http://localhost:8731>。页面用了 ES Module，需要通过这个本地服务打开。

规则测试：

```bash
npm test
```
